## 독립 검토에서 잡힌 중요한 오류 (고침)
1. `agent_type`은 `murba-good-work:builder`처럼 접두가 붙는다. 접두 없이 비교했으면 guard가 아무것도 못 막았다
2. status check는 저장소에 쓰기 권한만 있으면 누구나 올릴 수 있다. 자동 머지 게이트로 쓰려면 GitHub App을 출처로 지정해야 하고, Free 플랜 private 저장소는 필수 체크를 못 쓴다
3. 다음 AC로 넘어가는 전이가 없었고, AC를 커밋할 때마다 앞선 판정이 무효가 되는 모순 → qa 단계에서 전 AC 일괄 재판정
4. builder가 셋팅 단계의 보호 파일을 쓸 수 없는 모순 → 셋팅을 오케스트레이터 담당으로, 테스트 작성보다 앞으로
5. Stop hook에서 exit 2 + "파일 없음" 오류는 차단이 아니라 통과로 처리됨 → JSON 출력으로 차단
