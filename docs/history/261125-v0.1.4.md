## 알려진 문제
- BSD 형식 `sed -i '' '<스크립트>' <파일>`에서 guard가 스크립트 문자열을 파일 경로로 읽는다. test-write 단계에서 스크립트에 테스트 경로가 있으면 메인 세션 쓰기로 잘못 거부(회귀 t002, 실행은 계속). v0.1.4 전부터 있던 해석 결함이 새 규칙으로 드러남
