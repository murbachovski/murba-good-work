문제수정

guard가 따옴표 안 >를 쓰기로 오인따옴표 가리고 리디렉션 파싱

AC 의존 때문에 보류 남발[after:AC-x] 순서, 자동 해제
복합 Bash 명령 권한 거부단순 명령 규칙, 스크립트 파일, murba evidence-run
-p가 10분 뒤 서브에이전트 강제 종료서브에이전트 전경 실행
qa에서 찾은 결함을 못 고치고 끝남murba phase fix --ac <ID>
성능 AC가 측정 노이즈로 실패5회 이상 중앙값
