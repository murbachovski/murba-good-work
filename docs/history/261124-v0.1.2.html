PR #12 본문과 최종 상태의 차이

PR 본문은 첫 커밋 기준이다. 최종 동작은 [ADR 0005](../decisions/0005-skipped-runs-and-baseline.md)와 CHANGELOG를 따른다.

  • 게이트 적용: "승인 없이 생략한 실행" → build나 미검증 evaluate를 건너뛴 실행, 승인 여부와 무관
  • init --force: "처음 기준선 유지" → 새 실행으로 기준선을 다시 잡음(guard가 사람 확인 요구)
  • 테스트: 209 → 221(220 통과, 1 건너뜀)
