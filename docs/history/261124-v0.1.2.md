## PR #12 본문과 최종 상태의 차이
PR 본문은 첫 커밋 기준이다. 최종 동작은 [ADR 0005](../decisions/0005-skipped-runs-and-baseline.md)와 CHANGELOG를 따른다.
- 게이트 적용: "승인 없이 생략한 실행" → **build나 미검증 evaluate를 건너뛴 실행, 승인 여부와 무관**
- `init --force`: "처음 기준선 유지" → **새 실행으로 기준선을 다시 잡음**(guard가 사람 확인 요구)
- 테스트: 209 → 221(220 통과, 1 건너뜀)

## 내가 내린 결정
| 결정 | 틀렸을 때 비용 |
|---|---|
| `.murba/` 제외를 `.git/info/exclude` 대신 `.murba/.gitignore`로 | 비 git 환경은 이전과 같이 효과 없음. worktree·서브모듈에서 경로 계산이 필요 없음 |
| 재초기화는 기준선을 다시 잡음(3차 리뷰 뒤 되돌림) | 사람이 확인한 재초기화로 실행 중 변경을 기준선에 넣을 수 있음 |
| git 실패 시 게이트 거부(fail-closed) | git이 깨진 환경에서 approve·lock-tests·생략이 막힘. 오류 메시지와 run 스킬에 대응 안내 |
| 리뷰는 3차에서 멈춤(ADR 0003) | 3차 수정분은 리뷰어 재현 스크립트와 실제 실행으로만 확인 |
