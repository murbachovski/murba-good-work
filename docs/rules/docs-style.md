# 문서 규칙

## 언어
- 본문은 한국어. 기술 용어·코드 식별자는 원래 형태
- 스킬·에이전트 description은 한국어·영어 병기(트리거 인식용)
- 처음 나오는 영어 약어는 한 번 풀어 쓴다(예: AC = 수용 기준)

## 파일명
- 영문 소문자 + 하이픈(kebab-case). 공백·한글 금지
- 제목은 본문 첫 줄에 한국어로
- 날짜는 `YYMMDD`, 버전은 `vX.Y.Z`

## 형식
- 맨 위에 요약(무엇을, 왜, 결론)
- 표와 짧은 항목 위주. 한 칸에 한 가지
- 상태 표기: ✅ 완료 / ⚠️ 부분·주의 / ❌ 미완료·실패 / ⏸ 보류
- 주장에는 근거를 붙인다: 실행 결과, 파일 경로(`path:line`), URL
- 확인 수준을 밝힌다: 확인(직접 실행·원문 대조) / 추정 / 미검증

## 조사 문서
- 조사일을 적는다. 버전·수치는 조사일 기준
- 3rd-party 주장과 직접 확인한 사실을 구분한다
- 출처 URL을 빠짐없이 적는다
