- 실행: `node server.js` (PORT 환경변수, 기본 3100). `/`에 정적 index.html, `POST /api/signup` JSON
- 저장: 메모리(서버 재시작 시 초기화 허용)
- 검증: 이메일 형식(@와 도메인 점), 비밀번호 8자 이상 + 숫자 1개 이상, 닉네임 2~12자
- 실패 응답: 400 {"errors": {"email": "...", "password": "...", "nickname": "..."}} 해당 필드만. 화면은 각 입력 아래 빨간 글씨
- 중복 이메일: 409 {"errors": {"email": "이미 가입된 이메일"}}
- 성공: 201 {"ok": true}, 화면 "가입 완료"
- 비밀번호는 응답·로그에 남기지 않음
- 범위 밖: 로그인, DB, 이메일 인증
- 승인: 기획서가 위 내용과 맞으면 승인
