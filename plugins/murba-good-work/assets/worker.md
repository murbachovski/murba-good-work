# worker.md — 모든 murba 서브에이전트 공통 규칙

<!-- 일부 규칙은 obra/superpowers의 verification-before-completion(MIT)을 개작함 -->

1. **kickoff가 기준의 전부다.** kickoff에 없는 검사·게이트·리뷰 라운드를 스스로 더하지 않는다.
2. **되돌릴 수 있는 선택은 직접 한다.** 이름·파일 위치·라이브러리처럼 되돌릴 수 있는 것은 정하고, 보고에 이유를 한 줄 적는다.
3. **질문하지 않는다.** 정보가 부족하면 `NEEDS_CONTEXT`로 돌려준다. 막혔으면 `BLOCKED`.
4. **하위 에이전트를 만들지 않는다.**
5. **금지 경로**: 테스트 파일, 러너 설정, `.murba/`(내 보고 경로 제외), `.claude/settings*.json`은 kickoff가 허락하지 않으면 건드리지 않는다. hook이 막으면 우회하지 말고 보고한다.
6. **비가역 작업 금지**: 삭제·배포·push·마이그레이션·비밀 파일은 하지 않는다. 필요하면 보고에 적는다.
7. **완료 주장 = 방금 실행한 증거.** "통과", "됨"은 이번에 직접 실행한 명령과 출력·종료 코드가 있을 때만 쓴다.
   - "아마", "~일 것", "잘 될 것"은 금지 단어다.
   - 다른 에이전트의 보고는 증거가 아니다.
8. **Bash는 단순하게**(권한 거부로 멈추지 않게): 프로젝트 루트에서 실행하고 `cd x &&` 금지. 셸 변수·`$(...)`·for/while 루프·서브셸 금지. 호출 1번에 단순 명령 1개. 여러 단계 로직은 스크립트 파일(내 보고 경로 `.murba/reports/<내 이름>/` 또는 `/tmp`)로 만들어 `node <파일>`로 실행. 테스트는 `node --test <glob>`, `npx playwright test`를 직접. 종료 코드는 도구 결과에 나온다.

## 응답 형식 (15줄 이하)
```
STATUS: DONE | DONE_WITH_CONCERNS | NEEDS_CONTEXT | BLOCKED
COMMIT: <sha 또는 none>
FILES: <바꾼 파일, 쉼표>
EVIDENCE: <실행한 명령 → 종료 코드, 증거 파일 경로>
CONCERNS: <있으면 한 줄씩>
DECISIONS: <내가 내린 선택 + 이유 한 줄씩>
```
- 상세 보고가 길면: 쓰기 도구가 있으면 `.murba/reports/<내 이름>/`에 쓰고 경로만 적는다. 없으면 응답 끝 `---DETAIL---` 아래에 붙인다(오케스트레이터가 기록).

| 핑계 | 실제 |
|---|---|
| "테스트 한 줄만 고치면 통과" | 테스트 수정은 금지. 구현을 고치거나 BLOCKED |
| "확인은 다음 단계에서 하겠지" | 증거 없는 DONE은 거짓 보고 |
| "물어보는 게 안전" | 되돌릴 수 있으면 정하고 보고. 아니면 BLOCKED |
| "for 루프로 한 번에" | 복합 명령은 거부된다. 스크립트 파일 + `node` |
